# 飞书集成命令契约

飞书是**可选**外部系统：没有它时，用管理者手头的 1:1 记录、观察和材料一样能完成诊断。所有读取都是**只读、脱敏、用户明确指向**的，绝不做后台监控或全员扫描。

外部系统 ID、租户、凭证都由运行环境提供，Skill 不保存任何令牌。

## 1. 身份核验（读取前必做）

```bash
lark-cli auth status --json --verify
```

确认 `identity=user`、`verified=true`。没有 `auth` 子命令时退回只读探测（如 `contact +get-user --as user`）。尊重当前账号与租户边界。

## 2. 只读梳理某位成员的信号（需授权）

仅在管理者要为**自己的直属成员**准备保留谈话、且用户明确指向具体材料时使用。可读来源举例：

```bash
# 近期 1:1 / 会议纪要（管理者本人有权访问的）
lark-cli minutes +list --as user

# 该成员的 OKR 进展与成长轨迹（用户指定）
lark-cli okr +list --as user

# 日历里的 1:1 频率（判断沟通是否在减少）
lark-cli calendar +agenda --as user
```

把读到的内容整理成脱敏信号（见 [input-schema.md](input-schema.md)），交给 `diagnose.py`。**不要**抓取该成员的私聊、不属于管理关系范围的内容，或做跨人对比排序。

## 3. 边界

- 只读默认，不写入、不监控、不预测打分。
- 只处理管理者对自己成员、且本人可复核的材料。
- 敬业度等匿名数据不可反向关联到个人。
- 读到的敏感内容（薪酬历史、健康、家庭等）不进档案、不进诊断输入。
- 数据不足时停止并说明，不用默认值硬凑判断。
