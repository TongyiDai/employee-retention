# 五种离职状态

机器可读真源是 [five-states.json](five-states.json)，脚本只读它。本文件是给人看的说明。

一个人想走，很少是「突然」的，通常是长期感到下面五种之一。诊断的关键是**先判断他在哪个状态**，再对症干预——同样是"想走"，无聊和卡住需要的完全不同。

## 快速对照

| 他感到 | 他需要 | 一句话干预 |
| --- | --- | --- |
| 不被赏识 | 被重视 | 主动加薪、及时具体认可、把功劳还给他 |
| 孤独 | 被连接 | 创造真实协作与连接的机会 |
| 无聊 | 被挑战 | 交付有意思、有主导权的任务 |
| 卡住 | 在成长 | 一起做职业规划，讲清路径和差距 |
| 麻木 | 有热情 | 把工作和业务、客户、真实价值重新连接 |

## 1. 不被赏识 → 被重视

初始薪酬是锚点，定低了以后一直在追。**主动加薪，别等他开口**——等他开口，伤害已经造成，加薪会像补偿而不是奖励。很多管理者心里认可、却假设对方知道；不会的，要在 1:1 里直接、具体地说出来。有好事发生（晋升、里程碑、发布）时，**把舞台让给他**：让他自己宣布，你去放大，而不是替他宣布、抢了那个时刻。

## 2. 孤独 → 被连接

连接不能强迫，但可以创造机会：团队会、工作时间内的活动、能产生共同记忆的协作。面试时就如实说清团队文化的真实样子——如果团队大多成家、下班各回各家，就直说，别让人带着错误预期加入。

## 3. 无聊 → 被挑战

最好的杠杆是**交付有意思的任务**：写技术或业务方案、带新人、牵头跨团队、拿下一块你现在还握着的领域。别替他假设想要什么，直接问：「你觉得被挑战到了吗？现在的工作缺什么？」

## 4. 卡住 → 在成长

即使被挑战，看不到往上的路也会让人卡住。**职业规划是管理者的职责**，一起走一遍：下一级的要求是什么、他差多少、为什么、需要接什么任务、决策者需要看到什么证据。想走管理路线但没坑位时，让他在合适范围做副手、体验部分工作。**永远别承诺你控制不了的晋升时间线。**

## 5. 麻木 → 有热情

当一个人只在意技术或手艺本身、不在意产品和客户，投入会很脆弱。把团队和业务连起来：分享客户成功故事、请高管和团队聊、让他参与客户对话。**别假装热情**——找到一个他真能在意的客户、业务、手艺或归属点。

## 5 个脱离预警信号

等一个人递辞呈，你通常已经错过信号好几周。留意：

1. 不再在方案/架构讨论中发言
2. 不再推动更好的实践与标准
3. 文档、复盘这类「额外投入」消失
4. 长期问题/技术债被默默降级、不作解释
5. 汇报/站会更新越来越短、越来越机械

单个信号可能没事，**几个一起出现**，往往意味着这个人心里已经接受了别的机会，只等走流程。

## 风险等级

- **低**：单个弱信号，暂不足以判断，持续观察。
- **中**：数周内出现模式，需要在下次 1:1 主动核实。
- **高**：已直接表达想走、已有 offer 或已递辞呈，立即处理。
