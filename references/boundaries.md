# 隐私与边界

这枚 Skill 天然涉及对**具体个人**的判断。它能帮管理者更好地在意人，也可能被误用成监控或打分工具。边界是硬约束。

## 硬规则

1. **只对自己的直属成员用**
   使用者应是这名成员的直接管理者，且判断应当是本人能复核、能对话的。不对不归自己带的人做判断。

2. **不做离职预测打分**
   不输出「离职概率 87%」这类分数，不给人员排序，不做批量流失预测。诊断是为了帮一次具体的谈话，不是给一个系统性的评分。

3. **不做背对背画像**
   不在当事人完全不知情的情况下，把它当作给上级或 HR 的秘密评估工具。它的正当用法是帮管理者准备一次真诚的当面沟通。

4. **本地档案只存稳定事实**
   如果记录管理者或成员的背景档案，只存稳定事实与成长信息（职级、任期、优势、当前挑战），不存猜测、一时情绪、未解决的揣测，不存薪酬历史、健康、家庭等敏感个人信息。

5. **匿名数据不可反向关联**
   敬业度调研等匿名来源可以提示「哪个团队值得关注」，但不能反推到调研里的某个人。宏观信号和微观跟进之间靠管理者的直接观察连接，不靠数据反向识别。

## 为什么这么严

保留一个人，靠的是他相信你是**因为在意他**而行动，而不是因为怕失去他。一旦这件事变成打分、监控、背后评估，信任就没了，而信任正是保留的前提。宁可少一个「预测功能」，也不让这枚 Skill 变成让人不安的工具。

## 使用边界

- 用户要做监控、预测打分、人员排序或背对背画像时，停止并说明边界。
- 信号不足时，只给「下次 1:1 要核实的问题」，不硬下状态结论。
- 有些人留不住是正常的。好聚好散，不把挽留话术强加到已经决定离开的人身上。
